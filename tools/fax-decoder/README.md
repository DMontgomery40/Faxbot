# Faxbot Decoder (experimental)

A static page that turns Faxbot encoded fax pages back into the original document entirely in the browser; the fax is never uploaded. It reads the payload formats that `api/app/codec` writes (format 1: grid, run-coded and picture pages; format 2: capacity pages; Reed-Solomon repair, deflate or zstd, and AES-256-GCM with a shared key) from a PDF or TIFF of the fax, or from PNG and JPEG pictures of its pages. A page of a newer format, layout or capacity profile is refused with a sentence that says so. Pages are read as receivers keep them, as the Python reader does: a page that arrived inverted or upside down is turned back, and run-coded and capacity rows moved sideways or padded to another page width are moved back; a page resized after it arrived, or a small preview instead of the fax, is refused with a sentence that names the file to decode instead.
- `capacity-tables.js` holds the capacity layout's frozen tables, generated by `test/make_fixtures.py` from `api/app/codec/capacity_tables.json`; `api/tests/test_codec_decoder.py` checks that it carries exactly those bytes.

- Serve the folder over HTTPS or from `localhost` (for example `python3 -m http.server` in this folder): browsers load ES modules and WebCrypto only there, not from a `file://` address. The lead publishes it on faxbot.net/decode.
- Test it with `node --test test/decoder.test.mjs`. The fixtures come from `test/make_fixtures.py`, and `api/tests/test_codec_decoder.py` checks that they still match what the Python encoder makes.
- `vendor/fzstd.mjs` is fzstd 0.1.1 by Arjun Barrett (MIT, `vendor/fzstd-LICENSE`), unchanged.
