
# FreeSWITCH (existing installations)

Faxbot no longer offers FreeSWITCH as a provider for new setups. The Setup wizard does not have a FreeSWITCH choice. Existing installations with FreeSWITCH selected can continue to use their saved configuration for now; Faxbot plans to remove this provider in the next release.

If Faxbot has not yet removed the provider, it sends through the saved FreeSWITCH gateway and caller ID. Faxbot requires a real caller ID number from your carrier. A FreeSWITCH submission acknowledgement does not confirm fax delivery.
