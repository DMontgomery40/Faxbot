# Issue 55: missing-fact opportunities slice

Issue #55, its specification #48 and assessment #46 call for one outcome-grouped Opportunities page. #50 supplies Capabilities. The current page already loads 16 recommendation panels and optional AI results. Missing-fact advice is separate, and the aggregate CLI reads only 14 recommendation domains.

This change embeds the existing missing-fact advice in Opportunities and adds the same read to the aggregate CLI. It preserves the Facts to establish page and its portfolio planner. The embedded advice remains read-only, shows the recipient, evidence period, confirmation prerequisite, effort and next step, and labels unknown benefits honestly. It participates in the page's empty-state accounting and supports the existing section address convention. No settings, approval or activation behavior changes.

Implementation and validation:

1. Extract synthetic fact advice into one JSON fixture consumed by console and CLI regression tests. Verify the absent integration fails.
2. Reuse FactAdvice in an embedded mode, without the portfolio planner; add the facts section and count reporting to Opportunities. Include the existing fact read and renderer in the CLI aggregate, and expose a facts subcommand.
3. Test populated, loading, empty, denied, failed and retry behavior using mocks only. Run affected console suites, typecheck/build, CLI tests, console/CLI parity and settings coverage. Update README and generated CLI reference, then commit.
